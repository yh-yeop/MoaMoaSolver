# 한글 모아모아 솔버

메이플스토리 미니게임 '한글 모아모아'의 판(10 × 16)과 손패 3조각을 브라우저 화면 공유로 읽고,
조각을 어디에 어떻게 놓을지 추천하는 단일 HTML 웹앱입니다.
화면을 읽기만 하고 게임에는 어떤 입력도 보내지 않으며, 영상과 인식 결과는 브라우저 밖으로 나가지 않습니다.

👉 https://yh-yeop.github.io/MoaMoaSolver/

추천은 참고용입니다. 랭킹 보상이 걸린 플레이에 쓰기 전에 넥슨 운영정책과 이벤트 안내를 직접 확인하세요.

## 사용법
1. 게임을 창 모드나 테두리 없는 창 모드로 둡니다. 전체 화면(독점) 모드는 검은 화면으로 잡힐 수 있습니다.
2. 위쪽 **화면 공유** 탭 → **화면 공유 시작** → 게임 창을 고릅니다.
3. **캘리브레이션** (처음 한 번)
   - 판: 왼쪽 위 칸 모서리부터 오른쪽 아래 칸 모서리까지 드래그. 방향키로 1px 이동, Shift+방향키로 크기 조절
   - 카드 1~3: 조각이 그려지는 흰 칸만 드래그 ('○칸' 라벨과 회전·반전 버튼은 빼고)
   - 숫자 4곳(선택): 제거한 줄 수, 다음 능력 획득까지, 점 찍기·바꿔 뽑기 동그라미 숫자. 숫자만 감싸도록 ('번', '/7'은 빼고)
   - 판이 빈 상태(새 게임 직후)에서 **빈 판 기준 저장** → **저장하고 마치기**. 이때 숫자 0의 모양도 배웁니다
4. 능력 아이콘을 인식하려면 **보정 → 템플릿 등록**을 고르고, 아이콘이 보이는 칸을 누릅니다 (종류마다 최대 4개).
5. 마우스를 판 밖에 두면 추천이 미러 위에 그려집니다. ①이 지금 둘 수, ②③은 같은 턴의 다음 수입니다.
6. 숫자는 화면에서 읽습니다. 처음 보는 글자는 능력 패널에 '학습 필요'로 표시되니, 화면과 같은 값을 한 번 넣으면 그 모양을 배웁니다.
   이미 읽고 있던 숫자가 줄 삭제·능력 획득으로 바뀌면 새 글자도 스스로 배웁니다.

- 단축키: `Space` 다시 계산 · `1` `2` `3` 대안 보기 · `R` 보정 버리고 다시 인식
- 인식이 틀리면 **보정**으로 칸을 고치거나, 손패 카드를 눌러 모양을 고칩니다. 보정은 지금 한 수에만 적용됩니다.
- 카드 위에 마우스를 올리면(노란 카드) 커서가 조각을 가릴 수 있어, 읽은 모양이 사전에 없으면 직전 모양을 유지합니다.
- **데모** 탭에서는 판과 손패를 손으로 넣어 솔버만 써 볼 수 있습니다.
- **가상 화면**은 실제 게임 없이 캡처·인식을 시험하는 개발용 화면입니다 (데모 탭의 판을 게임처럼 그림).

## 조각 사전
조각은 모두 16종입니다. 처음 열면 보내 준 조각 이미지에서 읽은 14종이 사전에 들어 있습니다 (설정 → 조각 사전).
'확인 필요' 표시가 붙은 모양은 이미지가 작아 확실하지 않으니, 다르면 지우고 손패 편집으로 다시 저장하세요.
사전은 '배치 불가 조각' 평가, 바꿔 뽑기 판단(4종 이상), 시뮬레이터에 쓰입니다.

## 진행 상황
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 뼈대·규칙 | `config`(RULES), `storage`, 데모 모드 판·손패 입력 | 완료 |
| 2 솔버 | 방향 8가지, Worker 빔 탐색, 평가 함수, 능력 판단, 자체 테스트 | 완료 |
| 3 캡처 | 화면 공유, 영역 지정·미세 조정, 빈 판 기준 저장, 검은 화면 경고, 가상 화면(개발용) | 완료 |
| 4 인식 | 판·손패·아이콘 인식, 미리보기·예고 행 처리, 정합성 검사, 보정 UI, 히트맵, 조각 사전 | 완료 (가상 화면 기준, 실제 게임 검증 필요) |
| 5 추천 UI | 미러 오버레이, 추천 문장, 대안, 단축키, 상태 전이 | 완료 (실제 한 판 진행 검증 필요) |
| 6 튜닝 | 시뮬레이터, 가중치·θ 자동 조정 | 완료 |

인식 임계값(T_fill, T_gloss, T_icon, 미리보기 색 허용 오차)은 가상 화면에서만 맞춰 봤습니다.
실제 게임 화면에서는 히트맵을 켜고 설정의 슬라이더로 맞춰야 할 수 있습니다.

## 자체 테스트
디버그 → **자체 테스트**, 또는 주소 뒤에 `?selftest`를 붙이면 방향 생성, 줄 삭제 점수, 솔버 시나리오,
가상 화면 인식, 숫자 읽기 등 18개 항목을 검사합니다.

## 저장 키
- `hmm.settings.v1` 설정 (인식 임계값, 탐색, 가중치, 규칙, 캘리브레이션, 아이콘·숫자 모양)
- `hmm.dict.v1` 조각 사전
- `hmm.demo.v1` 데모 모드의 판·손패·능력 입력
- `hmm.live.v1` 화면 공유 모드의 능력 개수·제거한 줄 수
