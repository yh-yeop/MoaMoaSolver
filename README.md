# 한글 모아모아 솔버

메이플스토리 미니게임 '한글 모아모아'의 판(10 × 16)과 손패 3조각을 브라우저 화면 공유로 읽고,
조각을 어디에 어떻게 놓을지 추천하는 단일 HTML 웹앱입니다.
화면을 읽기만 하고 게임에는 어떤 입력도 보내지 않으며, 영상과 인식 결과는 브라우저 밖으로 나가지 않습니다.

👉 https://yh-yeop.github.io/MoaMoaSolver/

추천은 참고용입니다. 랭킹 보상이 걸린 플레이에 쓰기 전에 넥슨 운영정책과 이벤트 안내를 직접 확인하세요.

## 진행 상황
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 뼈대·규칙 | `config`(RULES), `storage`, 데모 모드 판·손패 입력 | 완료 |
| 2 솔버 | 방향 8가지, Worker 빔 탐색, 평가 함수, 능력 판단, 자체 테스트 | 완료 |
| 3 캡처 | 화면 공유, 영역 지정·미세 조정, 빈 판 기준 저장, 검은 화면 경고, 가상 화면(개발용) | 완료 |
| 4 인식 | 판·손패·아이콘 인식, 미리보기·예고 행 처리, 정합성 검사, 보정 UI, 히트맵, 조각 사전 | 완료 (가상 화면 기준, 실제 게임 검증 필요) |
| 5 추천 UI | 오버레이, 추천 문장, 대안, 단축키 | |
| 6 튜닝 | 시뮬레이터, 가중치 조정 | |

## 저장 키
- `hmm.settings.v1` 설정 (인식 임계값, 탐색, 가중치, 규칙, 캘리브레이션)
- `hmm.dict.v1` 조각 사전
- `hmm.demo.v1` 데모 모드의 판·손패·능력 입력
- `hmm.live.v1` 화면 공유 모드의 능력 개수·제거한 줄 수

## 로컬 실행
`getDisplayMedia`는 `localhost`나 HTTPS에서만 동작하므로 로컬 서버로 엽니다.
```
python -m http.server 5174
```
